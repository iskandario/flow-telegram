# FLOW · карманный диджей в Telegram

Telegram-бот + мини-апп, который сводит твои треки в DJ-сет прямо на телефоне.

## Возможности
- **Бот** принимает треки (музыка или файлы до 20 МБ), хранит личную библиотеку, отвечает на любые сообщения.
- **Авторизация через Telegram**: мини-апп проверяет подпись `initData` (HMAC-SHA256), каждый видит только свои треки.
- **Автомикс** в духе Apple AutoMix:
  - сетка битов (spectral flux + автокорреляция + уточнение по всему треку);
  - умный порядок сета по темпу (с учётом half/double time);
  - переход на 16-дольной фразе, предпочтительно в начале аутро (анализ энергии по тактам);
  - подстройка темпа ±8 % и плавный возврат к родному темпу за 16 долей;
  - равномощный кроссфейд с bass swap; echo-out для несводимых темпов.
- **Мэшап**: вокал уходящего трека поверх инструментала входящего. Разделение — нейросеть MDX (ONNX Runtime Web) прямо на устройстве, только окно перехода; дедлайн с откатом на обычный переход.
- **Светомузыка** через Home Assistant (Сбер, Яндекс, Xiaomi, Hue): команды по заранее известной сетке битов с упреждением на измеренную сетевую задержку.

## Структура
```
flow/          мини-апп + PHP-бэкенд (обычный хостинг, напр. reg.ru)
  api/bot.php     webhook бота
  api/app.php     API мини-аппа (initData-auth, прокси аудио из Telegram)
  api/setup.php   однократная настройка webhook и кнопки
  engine.js       движок автомикса/мэшапа (Web Audio)
  bpm.js          детекция BPM и сетки
  lights.js       светомузыка через Home Assistant
cloudflare/    та же серверная часть как Cloudflare Worker + KV
УСТАНОВКА.md   установка на хостинг
```

## Установка
- PHP-хостинг: см. [УСТАНОВКА.md](УСТАНОВКА.md).
- Cloudflare: `cd cloudflare && bash deploy.sh flow.твой-домен` (в РФ Cloudflare может замедляться провайдерами).
