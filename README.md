# FLOW · карманный диджей в Telegram

Telegram-бот + мини-апп, который сводит твои треки в DJ-сет прямо на телефоне.

## Возможности
- **Бот** принимает треки (музыка или файлы до 20 МБ), хранит личную библиотеку, отвечает на любые сообщения.
- **Авторизация через Telegram**: мини-апп проверяет подпись `initData` (HMAC-SHA256), каждый видит только свои треки.
- **Автомикс** в духе Apple AutoMix:
  - сетка битов (spectral flux + автокорреляция + уточнение по всему треку);
  - умный порядок сета по темпу (с учётом half/double time);
  - переход на 16-дольной фразе, предпочтительно в начале аутро (анализ энергии по тактам);
  - подстройка темпа ±8 % и плавный возврат к родному темпу за 16 долей;
  - равномощный кроссфейд с bass swap; echo-out для несводимых темпов.
- **Мэшап**: вокал уходящего трека поверх инструментала входящего. Разделение — нейросеть MDX (ONNX Runtime Web) прямо на устройстве, только окно перехода; дедлайн с откатом на обычный переход.
- **Светомузыка** через Home Assistant (Сбер, Яндекс, Xiaomi, Hue): команды по заранее известной сетке битов с упреждением на измеренную сетевую задержку.

## Структура
```
flow/          мини-апп + PHP-бэкенд (обычный хостинг, напр. reg.ru)
  api/bot.php     webhook бота
  api/app.php     API мини-аппа (initData-auth, прокси аудио из Telegram)
  api/setup.php   однократная настройка webhook и кнопки
  engine.js       движок автомикса/мэшапа (Web Audio)
  bpm.js          детекция BPM и сетки
  lights.js       светомузыка через Home Assistant
cloudflare/    та же серверная часть как Cloudflare Worker + KV
УСТАНОВКА.md   установка на хостинг
```

## Установка
- PHP-хостинг: см. [УСТАНОВКА.md](УСТАНОВКА.md).
- Cloudflare: `cd cloudflare && bash deploy.sh flow.твой-домен` (в РФ Cloudflare может замедляться провайдерами).

## Мобильная библиотека и VK

Mini App поддерживает поиск по библиотеке, фильтры VK / Telegram / файлы,
импорт аудио с телефона (до 20 МБ, хранится в IndexedDB на устройстве),
выбор треков для сета и навигацию с учётом safe area. Локальные файлы
работают и при открытии страницы в браузере без Telegram.

Для VK реализован вариант без регистрации VK-приложения и без компьютера
пользователя: номер и код вводятся внутри FLOW, сервер передаёт их в текущую
форму VK ID. Повторное открытие продолжает ту же попытку. Затем коннектор получает музыку
тем же способом, что FLOW Desktop. Удалённое окно оставлено для дополнительных
проверок. Коннектор поддерживает каталог VK,
плейлисты, поиск доступной версии трека и HLS через ffmpeg. PHP и Cloudflare
могут использовать один и тот же коннектор.

Для запуска нужен `vk-connector` с Chromium и ffmpeg. На настоящем аккаунте
подтверждены вход, чтение библиотеки из 1156 треков, восстановление зашифрованной
сессии в новом процессе и воспроизведение настоящего MP3 в WebKit через Range.
Это проверка на локальном сервере; внешний хостинг ещё не развёрнут.

Обычное прослушивание запускается кнопкой ▶ у трека: нативный аудиоплеер
запрашивает выбранный файл с сервера, без Blob и автоматического офлайн-кэша.
Автомикс загружает и анализирует текущий/следующий трек; предварительный анализ
всей библиотеки удалён. Сортировка по темпу применяется к уже известным темпам.
Нейросеть загружается только для мэшапа. Список VK — метаданные, не 1156 файлов.

Для личного размещения без дополнительной подписки подготовлен `render.yaml`
с `plan: free`. PHP-сайт можно разместить на уже имеющемся REG.RU. Шифрованные
сессии Render сохраняет через `FLOW_STATE_URL` в PHP-хранилище, поэтому его
эфемерный диск не должен заставлять пользователя входить при каждом запуске.
Это не гарантия круглосуточной доступности: Render Free засыпает через 15 минут
простоя, запускается около минуты и имеет ограничения трафика. Cloudflare
Containers требует платного плана и в бесплатную схему не входит.

Инструкция: [VK-MOBILE.md](VK-MOBILE.md). OAuth оставлен как необязательный
вариант для приложений с уже разрешённым Audio API.
