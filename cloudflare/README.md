# FLOW на Cloudflare

Бот, API и мини-апп в одном Cloudflare Worker. Библиотека — в Workers KV.
Для бота и интерфейса нужны Node.js и аккаунт Cloudflare. Для входа в VK без
Audio API дополнительно нужен серверный коннектор с Chromium и ffmpeg:
см. [VK-MOBILE.md](../VK-MOBILE.md). Бесплатный Worker его не заменяет.

## Запуск
```bash
cd cloudflare                 # из корня репозитория
./deploy.sh flow.torg-lot.ru   # со своим поддоменом (рекомендую)
# или
./deploy.sh                    # на адресе *.workers.dev
```
Скрипт сам: соберёт мини-апп → попросит войти в Cloudflare (браузер) → создаст хранилище →
задеплоит → спросит токен бота (ввод скрыт) → откроет страницу настройки бота.
На ней должно быть «✅ FLOW готов».

Ссылка мини-аппа для BotFather (Bot Settings → Configure Mini App): `https://flow.torg-lot.ru/`

## Обновление
Просто снова `./deploy.sh flow.torg-lot.ru`.

## Только для себя
Cloudflare → Workers → flow → Settings → Variables → добавить `ALLOWED_USERS` = твой ID (команда /id в боте).

## Лимиты бесплатного тарифа

У Static Assets лимит **25 MiB на файл**. Сборка автоматически разбивает большие
ONNX/WASM-файлы на части по 20 MiB и создаёт `flow-chunks.json`. Worker отдаёт
части последовательно по исходному URL, без сборки всего файла в памяти.
Проверяются число частей и их размеры; потерянная часть прерывает загрузку.
ETag позволяет повторно использовать кэш, проверяя версию после обновления.
Публикуйте Worker и всю папку `public/` одной сборкой через `deploy.sh`.

Музыка не загружается в Static Assets или KV: KV содержит записи библиотеки,
а аудио передаётся потоком из Telegram либо VK-коннектора. Ограничение FLOW
20 МБ на трек — отдельное ограничение приложения, не лимит Static Assets.
Файлы, выбранные с телефона, сохраняются локально в IndexedDB.

У Worker 128 МБ памяти на isolate и на бесплатном тарифе 100 000 запросов
в день. Частые кадры удалённого окна VK тоже расходуют запросы; постоянная
работа большого числа пользователей потребует пересмотра тарифа и архитектуры.
Текущие ограничения: [Workers](https://developers.cloudflare.com/workers/platform/limits/),
[KV](https://developers.cloudflare.com/kv/platform/limits/).

Проверка сборки и последовательной отдачи частей: `npm test` из корня репозитория.
