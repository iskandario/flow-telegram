# FLOW · Telegram-бот + мини-апп

## Что внутри
- `flow/api/bot.php` — бот (webhook): отвечает на любое сообщение, принимает треки (музыка или файлы до 20 МБ).
- `flow/api/app.php` — API мини-аппа; пускает только по подписи Telegram, каждый видит только свои треки.
- `flow/` — мини-апп: автомикс, мэшап (нейросеть прямо на телефоне), светомузыка через Home Assistant.

## Установка на reg.ru (5 минут)
1. ISPmanager → **Менеджер файлов** → папка сайта (обычно `www/твой-домен`).
2. Загрузи `flow-telegram.zip` → выдели → **Извлечь**. Появится папка `flow`.
3. Открой `flow/api/config.php` (Редактировать) и замени `ВСТАВЬ_СЮДА_ТОКЕН_ОТ_BOTFATHER` на токен бота. Сохрани.
4. Открой в браузере `https://твой-домен/flow/api/setup.php` — должно быть «✅ FLOW готов».
   Скрипт сам подключит webhook и кнопку «FLOW» в чате бота.
5. (Необязательно) BotFather → /mybots → бот → Bot Settings → Configure Mini App → Enable →
   URL `https://твой-домен/flow/` — тогда мини-апп откроется и из профиля бота.

## Требования
- HTTPS на домене (reg.ru выдаёт бесплатный Let's Encrypt: «SSL-сертификаты»).
- PHP 8.0+ с curl (по умолчанию на reg.ru есть).

## Если что-то не так
- setup.php подсвечивает красным, что именно не так.
- Сменил токен? Обнови config.php и снова открой setup.php.
- Только для себя: впиши свой ID (команда /id в боте) в `allowed_users`.
